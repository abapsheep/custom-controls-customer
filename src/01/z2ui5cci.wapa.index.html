abap2UI5 customer frontend extension

This BSP is a module container, not an application - it has no UI of its own. It serves this customer's frontend artefacts to the abap2UI5 frontend, which resolves them through the reserved resourceRoot z2ui5cci declared in its manifest.json.

Check the installation from the abap2UI5 endpoint instead: ?app_start=z2ui5_cl_ccc_sample_00
